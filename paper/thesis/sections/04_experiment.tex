\section{評価実験}
\label{sec:experiment}

\subsection{データ・評価条件・再現性}
\begin{itemize}
    \item \textbf{書くこと：} RCAEval RE1 Zenodo v2（record 14590730），OB・SS・TT各125ケース，合計375ケース．既知の注入時刻で分割し，前後それぞれ最大600点，短い区間は補完しない（\hyperref[ev:protocol]{E2}）．
    \item \textbf{表案：} データ版・障害種別・ケース数・入力列処理・学習区間・集約・設定・実行環境．AC@$k$と $\mathrm{Avg}@k=k^{-1}\sum_{j=1}^{k}\mathrm{AC}@j$，dataset別値とmacro平均を定義する．
    \item \textbf{注意：} 前処理には前後結合区間の完全定数列判定も含まれる．「全処理が正常のみ」とせず，AR学習・標準化の正常限定と区別する．HF版・BARO pilotを正式表へ混在させない．
\end{itemize}

\subsection{RQ1：既存手法との比較}
\begin{itemize}
    \item \textbf{書くこと：} 現行主方式とBARO RobustScorer，$\varepsilon$-Diagnosis，RCD，CIRCA adapter，RUN adapterを比較する．内部比較のRaw+BFは別枠に置く（\hyperref[ev:main]{E3}・\hyperref[ev:baselines]{E4}）．
    \item \textbf{表案：} dataset別・macroのAC@1/3/5・Avg@5，完了数・失敗数・空候補数．実行時間はwall-clockとケース時間合計，並列数・backendを区別する．
    \item \textbf{注意：} 共通データ・評価尺度と手法固有の入力・前処理・service化を分けて開示する．CIRCAのgraph学習区間や制約，RUNの正常限定学習を隠さない．
    \item \textbf{TODO：} 保存済みsummaryとcase IDを照合して正式表を確定する．RUNはこの保存先で未完了のため欠測扱い．低精度手法の空候補率・診断を確認してから解釈する．
\end{itemize}

\subsection{RQ2：構成要素と順位変化}
\begin{itemize}
    \item \textbf{書くこと：} 旧Observed-lag AR／RawとBF／GLRTの$2\times2$比較を設計動機として示す．現在のCounterfactual ARとRaw+BF・no-horizonの比較を別表で示す（\hyperref[ev:history]{E5}・\hyperref[ev:main]{E3}）．
    \item \textbf{図表案：} 正解サービスの順位改善／同一／悪化，Top-1獲得／喪失，dataset別・障害種別の内訳．完全順位をcase IDで対応付け，差の符号とMcNemar検定の対象を明記する．
    \item \textbf{注意：} 旧比較と現行方式を一つの$2\times2$に見せない．入力列処理や標準化等の世代差を確認し，構成全体の差をAR単独・BF単独の効果と断定しない．
    \item \textbf{TODO：} 最終方式に対する一軸のBF／GLRT比較として何が不足するか整理する．不足は追加実装へ直行せず，主張の限定か別研究作業かを判断する．
\end{itemize}

\subsection{RQ3：頑健性・感度・正常時診断}
\begin{itemize}
    \item \textbf{書くこと：} 単位・オフセット変換の順位保存，次数・定常性半径・horizon補正の一軸感度，正常内分割によるpseudo-faultを整理する（\hyperref[ev:sensitivity]{E6}・\hyperref[ev:robustness]{E7}）．
    \item \textbf{図表案：} 次数対精度のdataset別図，単位変換一致率，正常時max service log BFの分布，予測不確実性倍率の上位分位．全条件の表は付録へ置く．
    \item \textbf{注意：} 正常時スコアとRCA精度は別の評価軸．探索的な次数選択を独立テスト扱いせず，有意でない差を同等性の証明にもしない．
\end{itemize}
