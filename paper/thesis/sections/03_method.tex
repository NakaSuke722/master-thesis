\section{提案手法}
\label{sec:method}
% Notation: paper/shared/amber_notation.pdf に合わせ、x / y / r / z / E_i / R_s / pi を区別する。
% draft0では入力・処理・出力だけを示す。導出、仮定、ハイパーパラメータの説明は後続draftで展開する。
\label{sec:method-bf}

draft0は数式をゴリゴリ展開するよりも、入力・処理・出力の流れを図で示すことに注力したので提案手法の説明は省略する（Box等の資料に理論は載せている）。\\
AMBER（Autoregressive Modeling with Bayesian Evidence for Root Cause Analysis）は，本研究で提案するRCAの順位付け手法である．
\begin{itemize}
    \item \textbf{入力：} メトリクス$i$の観測値$x_{i,t}$を並べた時系列行列$X$，既知の障害開始時点$t_F$，各メトリクスの所属サービスを受け取る．
    \item \textbf{ARモデルによる正常時の予測：} 正常期間の平均・尺度で観測値$x$を標準化して$y$とし，正常期間だけでARモデルを学習する．障害期間は実測値を予測に戻さず，予測値を再帰的に使って，正常状態が続いた場合の予測$\widehat{y}^{(\mathrm{cf})}_h$を求める．
    \item \textbf{予測との差：} 正常期間の一時点先予測誤差$r^{(N)}_t$と，障害期間の反実仮想予測誤差$r^{(A)}_h$を，正常残差の中心・尺度で標準化する．障害期間には予測先に応じた不確かさ$q_h$も補正し，$z^{(N)}_t$，$z^{(A)}_h$を得る（ここではメトリクス添字$i$を省略）．
    \item \textbf{Bayes Factorによるスコアリング:} $z$の平均・分散を両期間で共有する$H_0$と，期間ごとに別の平均・分散を持つ$H_1$をBayes Factorで比較し，証拠スコア$E_i=\log\mathrm{BF}_i$を得る．
    \item \textbf{出力：} サービス$s$に属するメトリクスの$E_i$を上位最大三つの平均で集約して$R_s$とし，降順のサービス順位$\boldsymbol{\pi}$を返す．これは調査する原因候補の順位であり，原因である確率を表すものではない．
    \item 図案：入力・処理・出力の流れをフローチャートで示す．
\end{itemize}
