\section{関連研究}
\label{sec:related}

\subsection{既存の方法は何を手掛かりにするか}
\begin{itemize}
    \item まず，「普段からどれくらい値が変わったかを見る方法」と，「サービスやメトリクスの関係を調べ，変化の出発点を探る方法」に整理する．
    \item 比較表には，使うデータ，時系列の扱い，サービス間の関係情報が必要か，何を出力するかを並べる．
    \item 注意：既存研究を一括して「時間依存性を扱わない」みたいに書かない．個々の方法について文献を確認し，できることと前提条件を整理する．
\end{itemize}

\subsection{本研究をどこに位置付けるか}
\begin{itemize}
    \item 本研究では，各メトリクスの正常時の動きを予測し，その予測誤差の分布変化から順位を作る．サービス間の因果関係を表すグラフを入力として用意する必要はない．
    \item 既存の予測誤差による異常評価やベイズ的な変化検出と比べ，何を組み合わせ，原因候補の順位付けへどうつなぐ点が特徴かを書く．

\end{itemize}
