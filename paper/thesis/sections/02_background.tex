\subsection{サービスとメトリクスの関係}
\begin{itemize}
    \item サービスは「商品検索」「在庫確認」「決済」のように，システム内で一つの役割を担うプログラムの単位である．一方，メトリクスは各サービスの状態を数値として測る項目であり，時間とともに記録される．
    \item 一つのサービスから複数のメトリクスが得られる．たとえば「決済サービス」というサービスの中には，「CPU使用率」，「メモリ使用率」，「応答時間」などのメトリクスがある．同じ種類のメトリクスでも，どのサービスから得たかは区別する．
    \item 入力は障害前後のメトリクス時系列，出力は原因候補となるサービスの順位である．実験では意図的に不具合を起こしたサービスを正解とし，「どのメトリクスが真の原因か」まで当てる課題とは分ける．
    \item 図案：各サービスと複数のメトリクス→メトリクスごとの分析→サービス単位の候補一覧．正解情報は採点に使い，順位を作る際には使わないことを示す．
\end{itemize}

\subsection{分布が変わったかをベイズ的に比べる}
\begin{itemize}
    \item 「障害の前後で同じ分布」と「障害の前後で異なる分布」の二つの仮説を用意する．平均・分散を事前分布に関して積分した周辺尤度を比べる，と説明する．
    \item Bayes Factor（ベイズ因子，以下BF）は，二つの仮説の周辺尤度の比である．$\mathrm{BF}_{10}=p(D\mid H_1)/p(D\mid H_0)$ と書き，単に平均値の差を見る方法との違いを示す．
    \item 注意：BFが大きいことは，置いた仮説の下で分布変化を支持するという意味．そのまま「このサービスが原因である確率」にはならない．
\end{itemize}
