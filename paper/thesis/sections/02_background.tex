\section{背景}
\label{sec:background}

\subsection{データと「正解」をどう考えるか}
\begin{itemize}
    \item 一つのサービスから複数の観測項目が得られる．これらの観測項目はこの分野でメトリクスと呼ばれるが，本文ではできるだけ「観測項目」と書く．
    \item 入力は障害前後の時系列，出力は原因候補のサービス順位．実験では意図的に不具合を起こしたサービスを正解とする．「どの観測項目が真の原因か」まで当てる課題とは分ける．
    \item 図案：サービスごとの観測データ→分析→サービスの候補一覧．正解情報は採点に使い，順位を作る際には使わないことを示す．
\end{itemize}

\subsection{普段の動きを表す自己回帰モデル}
\begin{itemize}
    \item 自己回帰（AR）モデルは，直前までの値を使って次の値を予測するモデル．$x_t=c+\sum_{j=1}^{p}\phi_jx_{t-j}+\varepsilon_t$ を示し，本研究では正常時のデータから係数を推定すると説明する．
    \item 一時点先の予測と，予測値をさらに使って先へ進める予測を区別する．後者では先を予測するほど誤差が蓄積し得ることを，図と予測分散で説明する．
    \item 確認したい点：正常時の動きをARで近似する理由が伝わるか．必要な定常性などの仮定は，提案手法での使い方と結び付けて書く．
\end{itemize}

\subsection{分布が変わったかをベイズ的に比べる}
\begin{itemize}
    \item 「前後で同じ分布」と「前後で異なる分布」の二つの仮説を用意する．平均・分散を事前分布に関して積分した周辺尤度を比べる，と説明する．
    \item Bayes Factor（ベイズ因子，以下BF）は，二つの仮説の周辺尤度の比である．$\mathrm{BF}_{10}=p(D\mid H_1)/p(D\mid H_0)$ と書き，単に平均値の差を見る方法との違いを示す．
    \item 注意：BFが大きいことは，置いた仮説の下で分布変化を支持するという意味．そのまま「このサービスが原因である確率」にはならない．
\end{itemize}
